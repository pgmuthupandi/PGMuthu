## 📄 Pages Included

1. **Home (index.html)** - Landing page with hero section and featured projects
2. **About (about.html)** - Personal bio, journey, and statistics
3. **Portfolio (portfolio.html)** - Showcase of projects with filtering
4. **Skills (skills.html)** - Technical skills with progress bars and certifications
5. **Experience (experience.html)** - Timeline of work experience and education
6. **Blog (blog.html)** - Blog posts with categories and pagination
7. **Contact (contact.html)** - Contact form and communication information

- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices

## 🚀 Quick Start

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start customizing with your own content

## 📝 Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --text-color: #333;
}
```

### Content
Update the following files with your information:
- Replace placeholder text with your actual content
- Update links and contact information
- Add your projects and experience
- Update skills and certifications

### Images
- Replace gradient placeholders with actual images
- Add your profile photo in the About section
- Update project images in Portfolio
